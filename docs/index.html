How It Works

Transparent monitoring using PTY proxy technology

1

PTY Proxy

Creates a pseudo-terminal to intercept stdin/stdout without modifying your AI CLI tool.

↓
2

Void Observer

Measures void time from Enter to any key press. Auto-finalizes after 5 seconds of AI idle time.

↓
3

Snapshot System

Takes before/after snapshots of source files to calculate exact LOC changes.

↓
4

Local Storage

Saves data locally in JSONL format (~500 bytes per session). Privacy guaranteed.

Get Started in 30 Seconds

Simple installation with pip

$ pip install -e .
# Or from PyPI (when published)
$ pip install voidtally
✓ Successfully installed voidtally

Quick Start

  1. Monitor your AI CLI: voidtally run aider
  2. View the dashboard: voidtally board
  3. Filter by tool: voidtally board --tool aider
  4. Set up email reports: voidtally config email
