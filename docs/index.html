What It Does

⏱

Measure Void Time

Track waiting time across AI CLI sessions. Get precise measurements without interfering with your workflow.

📊

Track Code Changes

See exactly how much code changed per session. Line-by-line attribution with file-level breakdown.

📧

Daily Reports

Automated email summaries delivered each evening. HTML-formatted with session details and trends.

🔒

100% Local

All data stays on your machine. No cloud uploads, no tracking, complete privacy guaranteed.

Get Started

Terminal
$ pip install voidtally
$ voidtally run aider
# Work normally with your AI tool
$ voidtally board

Three Commands

  1. voidtally run <tool> Start monitoring
  2. voidtally board View dashboard
  3. voidtally config email Setup reports
